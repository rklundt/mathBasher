## Summary

Long-standing hardening items, no player-facing change.

1. **Dependency advisories.** `pnpm audit` reported 32 (4 critical, 18 high), all in build / test tooling (vite, vitest, sharp, postcss, nanoid…) or the undeployed `server/` (express → proxy-addr, body-parser, qs). Upgraded to the nearest patched versions: vite 6.4.4 and express 4.22.3 stay on their current lines; vitest + coverage 4.1.11 (from 3) and sharp 0.35.5 (from 0.34) are new majors, because the fixes don't exist on the old lines; `@types/node` 22; nested packages refreshed. `pnpm audit`: 0. Azure Static Web Apps only serves the built files (the build runs on GitHub's Node 22 runner), so these versions never run on Azure.
2. **Content-Security-Policy** in `public/staticwebapp.config.json`: only the site itself, Google Fonts, `data:`/`blob:` images / audio, and Cloudflare Web Analytics (enabled on the domain; found when the policy first went live on dev). Blocks Cloudflare's injected inline bot-detection snippet (not needed by the game). Verified on dev: the game loads and plays with no blocked requests of its own.
3. **GitHub Environments** `production` (main only) and `development` (development only), each with its own `AZURE_SWA_TOKEN`; the deploy workflow picks the environment by branch. The old repo-wide token secrets are removed after the first deploys through the environments.
4. **Pinned Actions + pull-request checks.** Every action pinned to a full commit SHA (checkout v7.0.1, setup-node v7.0.0, pnpm/action-setup v6.1.0, static-web-apps-deploy v1); new `ci.yml` runs typecheck, tests and build on every pull request. Prod deploys are no longer cancelled mid-run by a newer push.
5. **Azure tidy-up.** Tags (`project`, `environment`, `managed-by`) on both Static Web Apps and both resource groups; the dev app's leftover `development` preview environment deleted and its preview policy set to Disabled. Applied with targeted updates (tag merge, a PATCH of the one property) rather than a full Bicep redeploy, whose what-if showed it would drop the deploy metadata GitHub writes onto each app; the bicepparam files describe the same end state.
