# Sprint 2.13.1: Game groups and tile pictures

**Phase:** 2
**Status:** Closed — Released 2026-10-30 (in v2.14.0)
**Closed:** 2026-10-30
**Released:** 2026-10-30, with 2.14 as v2.14.0, on the owner's go

**Estimated effort:** About a day.

## Summary

Owner (2026-10-26): "I think we need a grouping for the types. i.e. Math has the original math-basher games (aliens, shooters, etc.) and now has math-fun (cute animals, balance scales, etc.) and our tiles really need a icon of a game's sprite/what it is too for kids to see and select."

## Decisions

1. **Two groups, as tabs on Game Select.** **Math Basher**: Alien Shoot, Asteroid Field, Space Escape!, Space Shooter. **Math Fun**: Math-a-lotl, Frog Splash, Penguin Slide, Bunny Garden, Balance Scale. Tabs (like the challenge picker's subject tabs) rather than two sections on one screen: each tab holds 4 or 5 tiles, so the tiles can be big enough for a picture and still read on a phone in landscape.
2. **Which tab opens:** the one picked last this visit, else the current game's. Focus lands on the current game when it's in the open tab.
3. **A picture on every tile,** cut from the art each game already ships: the big-headed alien, an asteroid, the Space Robot, the axolotl, the frog, an alien ship, the penguin, the bunny, and a little scale put together from Balance Scale's pieces.
4. **One small picture sheet, loaded at boot.** The game sheets load only when their game starts, so Game Select can't use them; loading them all up front would cost megabytes. `scripts/sprites/game-icons.mjs` cuts and packs the nine pictures into `hero/game-icons.webp` (96 px frames, about 40 KB).

## Stories

1. **Groups in core.** `src/core/gameGroups.ts`: `GAME_GROUPS`, `gameGroupOf`, `gameGroupById`. A test checks every math game is in exactly one group.
2. **The picture sheet.** The script above, `GAME_ICON_SHEET` in `spriteKeys.ts` (eager), a test that the sheet's size and frame order match the script and the code.
3. **Tiles with pictures.** `PlaceholderButton` takes an optional `icon` (any texture key and frame, size and padding): the picture on the left, the name and line centred to its right. Reusable for other tile screens.
4. **Game Select.** The tabs, two rows of tiles per tab (2 + 2, 3 + 2), the challenge chip and Back kept; Tab order chip, tabs, tiles, Back; Esc back to the menu. Layout numbers in `config.layout.challengeFlow.gameSelect`.

## Test plan

- 1280 × 720 and a phone in landscape (844 × 390): both tabs fit with the chip and Back; pictures and text readable.
- Keyboard: Tab through chip, tabs, tiles, Back; Enter on a tab swaps the tiles; Enter on a tile opens Difficulty for that game.
- Pick a Math Fun game, go back to the menu and Start again: Game Select opens on Math Fun with that game focused, on its backdrop.
- Challenge chip still opens the picker and returns here; Esc and Back go to the menu.
